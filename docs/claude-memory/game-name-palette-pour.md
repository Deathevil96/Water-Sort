The Unity game in this repo is **Palette Pour** (company Misal Interactive, package `com.misalinteractive.palettepour`, Google Play title "Palette Pour: Sort Puzzle"). It was briefly "Paint Magic Sort".

**Why:** MAGIC SORT is a registered trademark of Grand Games for the same genre (web search, Nov 2026); "Paint Sort" apps also exist. The user chose Palette Pour after a quick exact-name search found no conflict. It is NOT formally cleared: USPTO search and ideally a trademark attorney are still to do.

**How to apply:** never reintroduce "Magic Sort" or "Paint Sort" in names, text or art prompts. The name is set in `Assets/Scripts/Editor/ProjectSetup.cs`. The old logo and the text-bearing store images are parked in `ArtSource/old_name/`; the menu shows a code-drawn PALETTE / POUR wordmark until the user supplies the new `logo.png`. See also [[paint-sort-project]].
