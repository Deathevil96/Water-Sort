Use the Chrome browser named "Sumit's MacBook Air misal" (the Misal Interactive profile) for Play Console, AdMob and Firebase. Another connected browser opens AdMob on an old personal account ("deactivated due to inactivity", never click Reactivate) and Play Console on a "create developer account" page.

**Why:** on 2026-11-26 the session switched to the wrong browser; the user said "close that browser, use the other one with Misal Interactive profile".
**How to apply:** at the first browser call pick that browser (switch_browser shows it by name); if a Google page shows signup/deactivated screens, stop, close the tab and switch. Related: [[internet-ads-store-plan]].
